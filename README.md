# Linux Administration Lab 🐧

Hands-on Linux administration labs focused on real-world system administration, troubleshooting, security, storage, networking, and automation.

## 🎯 Objective

This repository documents my practical Linux learning journey through hands-on labs performed on virtual machines.

The goal is to build and demonstrate practical skills required for Linux System Administrator, Linux Engineer, Cloud Engineer, and DevOps roles.

## 🖥️ Lab Environment

- Linux: Rocky Linux 9
- Virtualisation: VirtualBox, Azure VM, VMware
- Shell: Bash 
- Version Control: Git & GitHub
